# math-learn：小学数学深度解析与举一反三

将小学及小升初数学题转化为孩子听得懂、家长能照着讲、学完能迁移一类题的学习闭环：**读懂题眼 → 确定性双重验算 → 分层直观讲解 → 精准错因诊断 → 抽象通用模板 → 阶梯举一反三**，并支持互动陪学与离线 HTML 学习单导出。

---

## 1. 易读数学符号规范（单一事实来源）

面向小学生与家长阅读、复制、微信转发及网页展示，**全程（含对话与 HTML 草稿）统一使用直观纯文本数学符号**：

- **运算与关系**：使用 `+`、`-`、`×`、`÷`、`=`、`>`、`<`、`≥`、`≤`、`≈`、`∶`（或 `:`）、`→`、`(...)`；未知数统一写小写 `x`、`y`，与乘号 `×` 清晰区分。
- **分数与小数**：行内分数写作 `3/4`、`25/3`（低年级讲读时可括号注音如“三分之二十五”）；带分数写作 `8又1/3`；循环小数写作 `0.333...`（必要时括号注明“3 循环”）。
- **指数与几何**：使用 `²`、`³`、`°`、`∠`、`△`、`⊥`、`∥`、`π`（如 `3.14 × 5²`、`∠ABC = 90°`、`△ABC`）。
- **算式排版**：关键算式用行内代码包裹（如 `120 ÷ (3 + 1) = 30`），避免与正文数字粘连。
- **零 LaTeX 源码**：输出中不使用 `$...$`、`$$...$$` 及 `\times`、`\div`、`\frac`、`\rightarrow`、`\approx` 等 TeX 命令，确保在微信、聊天窗口和离线网页中直接可读。

## 2. 模式与场景路由

先判断用户诉求与题量，进入对应工作分支：

1. **单题完整解析模式（默认）**：发来 1 道题要求解析、问知识点、要举一反三或整理错题 → 完整执行第 3 节 6 步流程与第 4 节模板。
2. **互动陪学模式**：用户明确说“引导孩子自己想”“别直接给答案”“陪娃做题” → 仅执行第 3.1 节陪学流程，严禁提前剧透最终答案或输出完整 6 步模板。
3. **多题批量解析模式**：一次发来 2 道及以上题目或整页错题 → 先逐题核对原题并给出「题号与答案速查表」，再逐题输出精炼主解与错因（单题不展开 4 变式），文末按共性薄弱模型集中提炼 1–2 个通用模板并配 2–4 道综合变式；若用户点名某题深讲，再切回模式 1。
4. **导出离线 HTML 模式**：用户要求“生成 HTML”“做成网页笔记”“电子错题卡”“存到下载目录” → 先完成解题与双重验算，再读取 [references/html-export.md](references/html-export.md) 落地单文件离线 HTML。

## 3. 标准解析工作流（单题完整解析模式）

按顺序执行以下 6 步，每一步达到完成标准后再进入下一步。

### 第 1 步：转录原题、剥离干扰与提炼“题眼”
- 若输入为图片，严格区分**印刷原题**与**学生手写笔迹/红笔批改**：逐字逐数转录印刷原题（核对数字、单位、问法及几何标注）；字迹模糊、裁切或关键条件缺失处显式标明 `[待核对：...]` 并追问，不静默补全。
- 若照片或文字包含**孩子已有的错误作答/草稿**，先记录其错误算式与卡壳位置，用于第 4 步个性化错因诊断。
- 提炼 1–3 个**题眼（显性关键条件与隐含条件）**，如“相向而行同时出发 = 看速度和”“至少保证 = 最不利原则”“给完一样多 = 原来相差 2 倍”。
- **完成标准**：原题文字与数据 100% 对齐，首行直接给出最终答案（含单位），方便家长秒速核对。

### 第 2 步：独立求解与确定性双重验算（零错题底线）
- 动笔讲解前，用**两种不同思路**算出同一答案，再把答案代回原题每一个条件正向核对是否自洽。
- **脚本精确验算**：在具备命令行工具的环境中，遇到多步小数/分数运算、复杂行程/工程/浓度、方程检验或**所有自编变式题**时，先静默运行一行 `python3`（优先使用 `fractions.Fraction` 做精确分数运算）验证结果，不依赖纯心算。
- 若发现原题条件矛盾、多解或存在小学阶段常见文字歧义，如实说明并分情况给出解答。
- **完成标准**：主解、次解与脚本/代入验算三者完全一致。

### 第 3 步：学段分层讲解（先直观后抽象，按需配图）
- **学段判定**：用户指明年级则严格对齐；未指明年级时，根据题干涉及知识点自动推断最低课标学段，且「方法一」默认优先选**不依赖方程的直观算术法**。

| 学段 | 主推直观解法 | 进阶 / 衔接解法 | 避免过早引入 |
|---|---|---|---|
| 1–3 年级 | 实物模拟、线段图/示意图、列表枚举、凑整法 | 移多补少、逆推法 | 方程、分数除法、负数 |
| 4–5 年级 | 份数法、扩倍去分数、假设替换、面积割补 | 归一归总、简单一元方程 | 多元方程组、抽象代换 |
| 6 年级 / 杯赛 | 份数/比例秒杀、不变量法、数形结合、模型转化 | 比与比例、工程设特值、方程设元 | 超出初中范围的高阶技巧 |

- 输出包含：
  1. **方法一（主推直观法）**：拆成 3–4 步短动作，每步写清「算什么 + 算式 + 单位」。遇到“除不尽”时，优先教**扩倍化份数**或**保留分数**，强调绝不中途四舍五入。遇到和差倍、行程、几何割补等强图形/数量关系题，用简洁文本线段或路线示意帮孩子“看见”关系。
  2. **方法二（进阶/巧算法）**：给出更高年级视角或更短算式的巧解（如比例法跳过中间量、拆数巧算等）；若为极简单一步计算题，改为「口算检验技巧」，不强凑牵强解法。
  3. **反向验算**：用 2–3 行把答案代回原题验证，培养“做完必验算”的习惯。

### 第 4 步：个性化错因诊断、知识点定位与“头号陷阱”
- **知识点清单**：明确指出所属**知识板块**（如“行程问题 / 火车过桥”）、**核心数学思想**（数形结合、转化、不变量、分类讨论等）与**关键计算技巧**。
- **错因诊断与头号陷阱**：
  - 若输入包含孩子的错误算式，**优先逐行指出孩子具体错在哪一步**（审题漏词、概念混淆、单位未统一还是计算失误），再用孩子听得懂的话讲清原因。
  - 同时补充（或无学生错解时直接还原）该题型最常见的 1 种典型错法与错因剖析。
- 需要匹配经典模型原型、直观画法、易错陷阱与母题迁移时，按需查阅 [references/problem-patterns.md](references/problem-patterns.md)。

### 第 5 步：万能解题模板与家长启发话术
- **万能解题口诀 / 流程**：抽象为 3–5 步可复用步骤（例如：`画路线 → 找同时出发段 → 定路程和/差 → 除以速度和/差`），沉淀“一类题的通法”。
- **家长讲题启发问句（1–2 句）**：提供不剧透答案的点拨提问（例如：“火车从车头刚上桥到车尾完全离开桥，车头一共往前走了哪两段路？”）。

### 第 6 步：举一反三（四阶梯变式训练）
围绕同一核心模型设计 4 道由浅入深的变式题（纯计算/巧算题可改为「同法巩固 → 逆向填数 → 变形提取 → 综合简算」）：

1. **变式 1（基础巩固）**：换数字与生活场景，主流程不变，附简洁解析与答案。
2. **变式 2（条件反转 / 对称变形）**：已知与未知对调，或反转角色关系，附简洁解析与答案。
3. **变式 3（经典母题迁移）**：映射到教材/杯赛高频同类原型，附简洁解析与答案。
4. **变式 4（高阶拓展）**：放宽一个隐藏前提或叠加一层条件，给出完整题干 + 升级思路点拨 + 最终答案（便于孩子挑战后核对）。

- **完成标准**：每道自编变式题的数字均经精确验算（优先 `python3` 核算），结果干净合理、符合生活常识且紧扣主模板。

### 3.1 互动陪学模式规则（模式 2 专用）

- 先在内部完成第 2 步双重验算（保证引导方向 100% 正确），但**严禁输出最终答案、算式结果或完整 6 步模板**。
- 每轮只输出：**1 句简短肯定/承接 + 1 个聚焦当前一步的题眼提示 + 1 个孩子能马上回答的小问题**。
- 孩子答对 → 肯定思路并推进到下一步；孩子答错或表示不会 → 降级为更细的脚手架（拆成更小一步，或用个位数举类比小例），不直接抛出全套解析（除非用户明确要求直接给答案）。
- 等孩子自己得出最终答案后，再一次补齐：**反向验算 + 本题易错点提醒 + 1–2 道巩固小变式**。

## 4. 默认输出结构模板（单题完整解析）

采用紧凑结构直接切入重点，无多余寒暄：

```markdown
### 题目与答案
> **原题**：...
**答案**：...
**题眼**：...

### 一、详细解析（两种解法）
#### 方法一：...（推荐）
#### 方法二：...（进阶/巧算）
> **反向验算**：...

### 二、错因诊断、知识点与头号陷阱
* **孩子错因诊断**（仅在输入含孩子错解时输出）：...
* **核心知识点**：...
* **头号易错陷阱**：常见错法 + 错因剖析

### 三、万能解题模板与辅导点拨
* **通用步骤**：第 1 步 → 第 2 步 → ...
* **家长启发提问**：...

### 四、举一反三（阶梯变式）
* **变式 1（基础巩固）**：题干 + 解析与答案
* **变式 2（条件反转）**：题干 + 解析与答案
* **变式 3（经典母题）**：题干 + 解析与答案
* **变式 4（高阶拓展）**：题干 + 升级思路点拨 + 答案
```
