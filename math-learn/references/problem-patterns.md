# 小学数学高频题型模型速查表

查阅时机：解析小学数学或小升初/杯赛题目时，用于快速匹配**直观解法、常见陷阱、通用模板与举一反三母题**。所有算式遵循 [SKILL.md](../SKILL.md) 第 1 节纯文本数学符号规范。

---

## 1. 平均数与钱物找补模型

- **题眼信号**：“同样多的钱”“平均分着吃”“多退少补”“合买分物”。
- **主推直观法**：**扩倍化份数法**（总数除不尽人数时，把 1 单位拆成“人数”份，彻底避开循环小数）。
- **通用流程**：`算总量 → 求应得（除不尽就扩倍）→ 算盈亏（实得 - 应得）→ 找对应（已知钱 ÷ 对应份数）`。
- **头号陷阱**：拿分得最少的人的实得量当基准，直接用两人差额算单价。
- **典型母题迁移**：
  - 合买水果分重找补（两付一收 ↔ 一付两收）
  - 郊游带面包分吃（甲带 5 个、乙带 3 个、丙没带，丙付 8 元 → 按多给出份数 `7 ∶ 1` 分，严防按 `5 ∶ 3` 分）
  - 多人拼车按里程分摊车费

## 2. 和差倍问题（含暗差 / 暗和）

- **题眼信号**：“共多少”“多多少”“是几倍”“多几/少几”“给完之后一样多”。
- **主推直观法**：**线段图 + 找 1 份量（标准量）**。
- **通用流程**：`画线段定 1 份 → 截多补少凑整倍 → 求 1 份量 → 回算各量`。
- **头号陷阱**：
  - “甲给乙 5 个后一样多”误以为原来差 5 个（实际差 `5 × 2 = 10` 个）。
  - 没把“多 3 个 / 少 2 个”先减掉或补齐，直接除以总倍数。
- **典型母题迁移**：年龄差不变问题、书架调书问题、两桶油互倒问题。

## 3. 盈亏问题（两次分配对比）

- **题眼信号**：“每人分 A 个多 M 个，每人分 B 个少 N 个”“两种分法”“刚好分完”。
- **主推直观法**：**两次分配差额对比法（总差 ÷ 单差 = 份数）**。
- **通用流程**：`统一分配对象 → 算总差（一盈一亏相加、双盈或双亏相减）→ 算单差 → 总差 ÷ 单差 = 人数`。
- **头号陷阱**：两次分配中有人标准不同（如“一人分 3 个，其余人分 5 个”），未先转化成统一标准就直接套公式。
- **典型母题迁移**：宿舍住人问题、绳子折几折量井深、买东西钱多/钱少问题。

## 4. 鸡兔同笼与假设替换模型

- **题眼信号**：两种物品混合、已知总个数与总价值/总腿数，或“答对加分、答错倒扣分”。
- **主推直观法**：**假设全是某一种 → 算总差 → 每次替换消去多少差**。
- **通用流程**：`假设全是甲 → 算假设总量与实际差额 → 算单个替换差 → 总差 ÷ 单差 = 乙的数量`。
- **头号陷阱**：倒扣分题（如答对 `+5` 分、答错 `-2` 分）把单个替换差算成 `5 - 2 = 3` 分（实际是 `5 + 2 = 7` 分，不仅没拿到 5 分还倒扣 2 分）。
- **典型母题迁移**：硬币面值问题、大小船租船问题、打靶/竞赛倒扣分问题、三物鸡兔（先合并两类）。

## 5. 行程问题（相遇、追及、流水、火车过桥）

- **题眼信号**：“相向而行”“同向追及”“顺水/逆水”“完全通过大桥/错车”。
- **主推直观法**：**路线示意图 + 速度合成（相遇看速度和、追及看速度差）**。
- **通用流程**：`画起点与方向 → 找同时出发段 → 确定路程和或路程差 → 路程 ÷ 速度和/差`。
- **头号陷阱**：
  - 火车过桥忘记加车长（完全通过 = `桥长 + 车长`；完全在桥上 = `桥长 - 车长`）。
  - 两岸往返多次相遇忘乘次数规律（第 n 次相遇共行 `2n - 1` 个全程）。
  - 流水行船忘记顺水与逆水速度差等于 `2 × 水速`。
- **典型母题迁移**：环形跑道相遇追及、扶梯上下行问题、时钟追及问题。

## 6. 工程与牛吃草问题

- **题眼信号**：“单独做需几天，合作需几天”“一边进水一边排水”“草匀速生长”。
- **主推直观法**：
  - 工程：**设工作总量为天数的最小公倍数**（化分数效率为整数份数，中低年级极易理解）。
  - 牛吃草：**对比两种吃法消去原有草 → 先求每天长草量 → 再求原有草量 → 派一部分牛专吃新草**。
- **通用流程**：`设总份数（或求新草速度）→ 算每日效率 → 按合作/交替分段核算`。
- **头号陷阱**：两人交替工作最后一步不需要完整周期，直接用 `总量 ÷ 周期工作量` 会多算时间。
- **典型母题迁移**：进水管与排水管同开、检票口排队放行、抽水机抽井水。

## 7. 图形与几何（面积割补、等积变形、容斥、立体切拼）

- **题眼信号**：求阴影面积、不规则多边形、拉窗帘/蝴蝶/一半模型、叠放重叠面积、立体切割增表面积。
- **主推直观法**：**割（切块）、补（大减小）、移（平移/旋转拼整）、等底等高拉窗帘**。
- **通用流程**：`标全已知边角 → 寻找规则图形或等底等高关系 → 做辅助线转化 → 分步算面积/体积`。
- **头号陷阱**：
  - 重叠图形（容斥型阴影）忘记“相加后减去多余空白”或重复减去重叠部分。
  - 三角形面积漏写 `÷ 2`，圆面积把直径当半径直接平方，立体切 1 刀忘记增加的是 **2 个**切面。
- **典型母题迁移**：一半模型、鸟头/沙漏/蝴蝶模型、方中圆与圆中方、正方体/长方体切拼表面积变化。

## 8. 经济浓度与分数百分数（单位“1”与不变量）

- **题眼信号**：“提价/降价百分之几”“加水/加盐/蒸发”“原价、折上折、利润率”“比谁多/少几分之几”。
- **主推直观法**：**抓不变量 + 设特值（把单位“1”设为 100 或方便整除的整数）**。
- **通用流程**：`锁定单位“1”与不变量 → 设好算的特值 → 用不变量前后占比反推总量变化`。
- **头号陷阱**：
  - 先涨 10% 再降 10%，误以为回到原价（实际 `100 × 1.1 × 0.9 = 99`，降了 1%）。
  - 加水稀释浓度时误把盐水总量当不变量（实际是**溶质/盐的质量**不变）。
- **典型母题迁移**：商品打折与保本定价、盐水兑水/加盐、男生转入后女生人数不变。

## 9. 比与比例、正反比例

- **题眼信号**：“甲与乙的比是……”“按比例分配”“比的前项/后项变化”“速度与时间、齿轮齿数与转数”。
- **主推直观法**：**连比通项统一份数 + 抓不变量（和不变 / 差不变 / 单量不变）**。
- **通用流程**：`找不变量 → 把两处比例中的不变量化为最小公倍数 → 统一每份大小 → 求 1 份对应量`。
- **头号陷阱**：
  - 把“长方形周长按长宽比分配”直接用周长除以 `长 + 宽`（忘记先 `周长 ÷ 2` 求出一条长与宽的和）。
  - 行程/工程里把正反比例搞反（路程一定时，速度与时间成**反比**，不是正比）。
- **典型母题迁移**：三量连比化简、两班人数调动前后比例变化、大小齿轮啮合转数、地图比例尺换算。

## 10. 计算与巧算（纯算式题型）

- **题眼信号**：大数乘除、带小数的加减乘除、长串分数求和、等差数列、“规定 `a ★ b = ...`”。
- **主推直观法**：**凑整拆数、提取公因数（乘法分配律）、分数裂项抵消、倒序相加**。
- **通用流程**：`先观察数字特征（25×4、125×8、相同因数、分母相邻乘积）→ 变形构造结构 → 消去或凑整 → 尾数/估算核验`。
- **头号陷阱**：
  - 除法滥用分配律，把 `120 ÷ (3 + 5)` 错算成 `120 ÷ 3 + 120 ÷ 5`（除法只对**被除数**拆分有效）。
  - 分数裂项 `1/(n × (n + 2))` 忘记乘 `1/2`（母积子差，分子不是两因数之差时必须补系数）。
  - 去括号遇减号/除号忘记变号（`a - (b - c) = a - b + c`）。
- **变式阶梯改法**：纯计算题的 4 道变式调整为「同法换数巩固 → 逆向填括号/缺数 → 需先变形再提取公因数 → 综合巧算」。

## 11. 数论与整除（小升初高频）

- **题眼信号**：“能被 3、9、4、25、7、11 整除”“最大公因数 / 最小公倍数”“余数相同 / 差相同”“质数、合数、奇偶性”。
- **主推直观法**：**整除特征判别 + 短除法分解质因数 + 余数同余（同余减余、同补加补）**。
- **通用流程**：`按末位/数字和筛范围 → 分解质因数配对 → 结合余数条件（余同加余、缺同减缺）缩小候选 → 逐一验算`。
- **头号陷阱**：
  - 误把 `1` 当质数，或忘记 `2` 是唯一的偶质数。
  - 求“最少需要多少”时，把最大公因数和最小公倍数用反（切小块/分组看**最大公因数**，拼大块/同时再遇看**最小公倍数**）。
  - 分解质因数算约数个数时漏记指数 `+ 1` 再相乘。
- **典型母题迁移**：瓷砖裁切与拼接、韩信点兵（物不知数）、末位 0 的个数（数因数 `5`）、奇偶性判能否完成操作。

## 12. 还原（倒推）与统筹最值

- **题眼信号**：“卖出一半又多 2 个，最后剩……”“怎么安排时间最短 / 费用最少”“每次最多烙 2 张饼”。
- **主推直观法**：
  - 还原：**画正向操作流程图（框 + 箭头）→ 从终点反着往回算（加变减、乘变除）**。
  - 统筹最值：**满负荷不空锅（烙饼） / 短任务优先（排队等候） / 少向多靠拢（调运汇合点）**。
- **通用流程**：`按顺序画出每一步变化 → 从最后结果逐步逆算（或列出时间/费用约束）→ 正向代回验证`。
- **头号陷阱**：
  - 还原问题把“多 2 个”和“一半”的逆序搞反（正向是“先 ÷ 2 再 - 2”，倒推必须“先 + 2 再 × 2”）。
  - 烙 3 张饼（每面 3 分钟、锅最多放 2 张）误算为 `4 × 3 = 12` 分钟（交替满锅只需 `3 × 3 = 9` 分钟）。
- **典型母题迁移**：猴子吃桃、甲乙丙互给钱后同样多、打水/修车总等候时间最短、仓库合并运费最省。

## 13. 周期、植树与容斥计数

- **题眼信号**：“第 2026 个是什么”“两端栽/不栽、封闭环形”“既会 A 又会 B”“至少有多少人”。
- **主推直观法**：
  - 周期：**先圈出一组完整周期 + 余数看位置（余 0 看最后一个）**。
  - 植树：**画 3 棵小树验证间隔数**（两端栽 `棵数 = 间隔 + 1`，封闭圈 `棵数 = 间隔`）。
  - 容斥：**画韦恩图（两圆/三圆重叠）**。
- **头号陷阱**：周期问题把“余数为 0”误看成第 1 个；爬楼梯从 1 楼到 6 楼误算为爬了 6 层（实际 `6 - 1 = 5` 层）。
- **典型母题迁移**：敲钟报时、锯木头段数与次数、日期星期推算、方阵实心与空心人数。

## 14. 抽屉原理、枚举与逻辑推理

- **题眼信号**：“至少取多少个才能保证……”“有多少种不同方法”“三人中只有一人说真话”。
- **主推直观法**：
  - 抽屉原理：**最不利原则（倒霉到极致，差 1 个就能成功，最后再 `+ 1`）**。
  - 计数枚举：**按大小/高位有序树状分类，不重不漏**。
  - 逻辑推理：**找矛盾句或假设法列表打勾叉**。
- **头号陷阱**：抽屉原理混淆“可能”与“保证”，漏加最后的 `+ 1`；计数未固定顺序导致重复统计。
- **典型母题迁移**：摸黑取同色袜子/小球、数字卡片组数、真假话推理与赛制场次。
