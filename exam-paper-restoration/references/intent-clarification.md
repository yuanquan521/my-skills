# 意图辨析与高歧义判定指南 (Intent Clarification)

本文件补充 [SKILL.md](../SKILL.md) 中需要按需查阅的边界判定准则、完整符号对照表与用户提示词映射。

---

## 一、物理去干扰 vs 语义去干扰

| 维度 | 真实需求（物理卷面去痕） | 误读反例（严禁） |
| :--- | :--- | :--- |
| **目标** | 还原**给学生重做**的空白原卷 | 提炼成给成人看的纯数学模型 |
| **题干处理** | 完整保留背景故事、冗余数字、生活百科标签 | 擅自删掉背景或非关键数据，缩写成两句话 |
| **结果影响** | 保持原卷考点设计与阅读理解难度 | 破坏原题情境与真实难度 |

> [!WARNING]
> 凡涉及作业辅导、错题本、重测练习卷，“去干扰”一律指**清除卷面笔迹、草稿、批改与邻题干扰**，绝不改写原题文字。

## 二、手写痕迹 vs 原卷印刷标注的判别标准

当几何图或题干旁出现数字、角度、记号时，按以下四项综合判定，**禁止仅凭“题干已写过该数字”就武断删掉图上标注**：

1. **字体与笔画**：印刷体粗细均匀、字形规整、基线齐平；手写体笔画有起收锋、倾斜度不一或明显歪斜。
2. **颜色与介质**：印刷体通常与题干同色（纯黑/深灰/套色蓝）；铅笔灰、蓝黑圆珠笔、红笔批注多为手写。
3. **排布位置**：印刷标注通常与线段保持统一间距且有规整引线/大括号；手写标注常贴边、压线或塞在空白角落。
4. **内容性质**：解题中间量（如算出的高、阴影拆分结果、辅助虚线）必然为手写或批改；已知顶点字母、直角小方框、已知角度弧线通常为原卷印刷。

**存疑兜底规则**：若因拍照模糊、黑白复印或字迹工整导致无法 100% 确定某标注是否为印刷体，**默认保留该标注**，并在交付末尾的「待人工核对清单」中注明（例如：“第 10 题图上底边旁的 `10` 疑似手写，暂予保留，请核对原卷”）。

## 三、模糊、遮挡与裁切残缺处理协议

实拍试卷常出现反光、折痕、红笔涂死或手指遮挡，严禁凭数学常识静默“脑补”原数字或原字：

| 异常情况 | 正文占位写法 | 核对清单说明 |
| :--- | :--- | :--- |
| 局部反光/模糊，能大致辨认 | `[待核对：疑似 78]` | 注明模糊位置与推测依据 |
| 被涂改液/红笔完全盖住 | `[待核对：此处被涂改遮挡]` | 提醒用户对照原卷补填 |
| 拍照边缘把题干或选项截断 | `[待核对：后续内容被拍裁切]` | 说明缺失的是哪一问或哪个选项 |
| 图上关键顶点字母看不清 | 按上下文暂标字母并加注说明 | 明确指出哪个顶点字母为推测 |

## 四、中小学标准数学符号完整对照表

输出时统一采用教科书规范印刷符号，严禁英文代称或编程符号：

| 符号类型 | 严禁出现的错误写法 | 标准写法（Unicode / LaTeX） | 说明 |
| :--- | :--- | :--- | :--- |
| **加减法** | `plus`、`minus` | `+`、`-`（或 `−`） | 标准算术加减号 |
| **乘法** | `*`、`x`、`X`、`times`、`mult` | `×` / `\times` | 字母变量相乘按原卷写 `ab` 或 `a·b` |
| **除法** | `div`、`divide`、`/` | `÷` / `\div` | 仅原卷印制斜杠分式时保留 `/` |
| **分数与带分数** | 强行改写上下分式为 `3/4` | `\frac{3}{4}`、`2\frac{1}{3}` | 保持原卷分式形态 |
| **比号** | `ratio`、`to`、`/` | `∶` / `:` | 数学比号 |
| **循环小数** | `0.333...`（原卷为循环点时） | `0.\dot{3}`、`0.\dot{1}\dot{2}` | 与原卷循环点保持一致 |
| **角与度数** | `angle A`、`45 deg` | `∠A`（`\angle A`）、`45°`（`45^\circ`） | 含角编号如 `∠1`（`\angle 1`） |
| **平行与垂直** | `parallel`、`perp` | `∥`（`\parallel`）、`⊥`（`\perp`） | 几何关系符号 |
| **三角形与弧** | `triangle ABC`、`arc AB` | `△ABC`（`\triangle ABC`）、`\widehat{AB}` | 标准几何图形记号 |
| **相似与全等** | `sim`、`cong` | `∽`（`\sim`）、`≌`（`\cong`） | 初中几何常用 |
| **约等于与比较** | `approx`、`geq`、`leq`、`neq`、`!=`、`>=`、`<=` | `≈`（`\approx`）、`≥`（`\ge`）、`≤`（`\le`）、`≠`（`\neq`） | 杜绝编程语言比较符 |
| **单位** | 擅自中英互换（把“平方分米”改 `dm²`） | 原卷写中文留中文，写符号留 `\text{cm}^2` / `cm²` | 100% 忠实原卷写法 |

## 五、常见用户提示词意图映射

| 用户提示词 | 执行指令 |
| :--- | :--- |
| “重新整理图中题目，去掉干扰因素” | 题干一字不改；清空手写、草稿、红圈、打叉；重绘干净原图 |
| “帮我把这个题做成错题本格式” | 原题原样录入 + 空白题图 + 末尾折叠（或附录）参考答案与解析 |
| “只把错题整理出来” | 仅筛选带错号/扣分/订正痕迹的题；成品同样清空所有批改标记 |
| “生成一份可打印的空白卷 / 错题卷” | 还原全部目标题后，按 [question-types-and-output.md](question-types-and-output.md) 输出自包含可打印 HTML |
| “试卷还原 / 卷面翻新 / 提取原题和图” | 100% 空白卷面还原，匹配独立干净原图 |
