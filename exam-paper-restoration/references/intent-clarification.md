# 意图辨析与防歧义指南 (Intent Clarification)

在辅助学生整理试卷、错题时，AI 极易对用户的提示词产生逻辑误读。以下是常见的高频歧义与标准处理准则。

---

## 经典误区剖析

### 误区一：把“物理卷面去痕”当成了“数学思维去干扰”

| 概念 | 真实需求（物理卷面去痕） | 常见误读（数学思维去干扰） |
| :--- | :--- | :--- |
| **目标** | 制作**给学生重新练习**的空白卷面 | 抽象为给成人看的数学公式 |
| **对题干的处理** | 保留背景故事、冗余数字、生活百科标签 | 擅自把背景和非关键数字删掉，缩成两句话 |
| **对题目的影响** | 真实试卷原貌不变 | 改变了考题难度与题目情境设计 |

> [!WARNING] **核心准则**  
> 只要用户是在辅导作业、整理错题本、重测练习卷，**“去干扰” 永远等于 “卷面去笔迹与涂改”**，绝对不是“重新改写题干”。

---

### 误区二：在原图上画蛇添足（擅加辅助线与草稿数值）

很多学生错题时在原图上画了辅助线或写了数字：
- **错误做法**：AI 重新画图时，自作聪明把辅助线、阴影面积公式、解题标注画到了图上。
- **正确做法**：原图只保留试卷最初印制的状态。辅助线属于解题步骤，只能放在“答案解析”中，绝不能出现在题目原图中。

---

### 误区三：多图排版混淆

在正规考卷中，选择题或填空题的图形往往集中排在下方（如第 10 题、第 11 题、第 12 题并排）。
拍照时往往会把一整排都拍进来。
- **正确做法**：
  1. 仔细观察图下的文字注记：例如 `（第 10 题）`、`（第 12 题）`。
  2. 每一道题只配它自己的那张图，另外两张图必须从当前题目中切除，分别归位到其对应的题目中。

---

### 误区四：配图比例失真与版面尺寸失控

重绘几何图时容易犯两类极端错误：
1. **几何比例失真（严重影响做题直觉）**：
   - 题干明确说 $\angle A = 45^\circ$，结果画成了 $20^\circ$ 锐角或 $80^\circ$ 大角；
   - 题干明确说 $AE = 3BE$，结果 $E$ 点画在了线段正中间（$1:1$），直接破坏了几何等高模型的直观感知。
   - **正确做法**：严格按照题目数据比例确定顶点坐标，保证几何关系的真实性。
2. **画幅尺寸失控（过大或过小）**：
   - 输出了一张 1000px 宽的大图，占满几屏，排版非常臃肿；
   - 或者输出了一张 80px 的缩略图，字母标签挤在一起无法看清。
   - **正确做法**：保持在宽 280px ~ 360px、高 180px ~ 250px 的适中卡片尺寸，留白 10% ~ 15%，美观且适合打印阅读。

---

### 误区五：数学与运算符号“代码化”或“英文代称化”

在整理中小学试卷或题卡时，部分 AI 或 OCR 工具习惯性输出编程语言符号或英文词汇（如 `div`、`times`、`*`、`deg` 等），这严重破坏了标准试卷与教科书的严肃性与规范性：

| 符号类型 | 常见错误（严禁出现） | 标准写法（必须使用） | 说明 |
| :--- | :--- | :--- | :--- |
| **加法 / 减法** | `plus`、`minus` | `+`、`-`（或 `−`） | 标准数学加减号 |
| **乘法** | `*`、`x`、`times`、`mult` | `×`（LaTeX `\times` 或 Unicode `×`） | 杜绝星号与英文代称 |
| **除法** | `div`、`divide`、`/` | `÷`（LaTeX `\div` 或 Unicode `÷`） | 必须使用标准除号（除非原卷印制即为斜杠） |
| **比号** | `ratio`、`to`、`/` | `∶`（数学比号或 LaTeX `:`） | 严禁英文比号 |
| **角与度数** | `angle A`、`45 deg` | `∠A`（`\angle A`）、`45°`（`45^\circ`） | 标准几何角与度数记号 |
| **平行与垂直** | `AB parallel CD`、`perp` | `AB ∥ CD`（`\parallel`）、`⊥`（`\perp`） | 标准几何关系符 |
| **三角形** | `triangle ABC` | `△ABC`（`\triangle ABC`） | 标准几何图形符 |
| **约等于与比较** | `approx`、`geq`、`leq`、`neq` | `≈`（`\approx`）、`≥`（`\ge`）、`≤`（`\le`）、`≠`（`\neq`） | 杜绝英文缩写或未渲染宏名 |

## 用户提示词映射表

当用户输入以下提示词时，应自动激活本工作流：

| 用户提示词 | 真实意图与执行指令 |
| :--- | :--- |
| “重新整理图中题目，去掉干扰因素” | 题干一字不改；清空手写、草稿、红圈、打叉；重绘干净原图 |
| “帮我把这个题做成错题本格式” | 原题原样录入 + 空白题图 + 末尾折叠参考答案及考点分析 |
| “试卷还原 / 卷面翻新” | 100% 空白卷面还原，不带任何笔迹 |
| “提取原题和图” | 纯净原题题干 + 单独匹配对应原版图 |
